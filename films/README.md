## Export in Premiere

1. Mark a 30-second in/out on the best passage (not the titles, not the end card).
2. File → Export → Media.
3. Format: H.264. Preset: Match Source – High Bitrate.
4. Check Use Maximum Render Quality. Video: 1080 × 1920, 25 or 30 fps, Profile High, Level 4.1, Bitrate 8 Mbps VBR 1-pass.
5. Audio: AAC, 48 kHz, 128 kbps.
6. Target size: under 15 MB. If the file is over 20 MB, drop bitrate to 6.
